# コミット

1. `git status` と `git diff` で差分全体を確認する。
2. 差分を意味のある最小単位に分割する必要があるかを検討する。
   - 1 コミットには 1 つの関心事のみを含める (例: リファクタリングと機能追加は分ける)。
3. 分割した単位ごとに以下を繰り返す。
   1. 対象の変更のみをステージングする (`git add <path>` / `git add -p`)。
   2. `git diff --staged` でステージングされた差分全体を確認する。
   3. 差分全体を踏まえて、日本語でコミットメッセージを記述しコミットする。
4. `git log --oneline` で作成したコミットをユーザーに伝える。
